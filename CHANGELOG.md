If the version realease is `a.b.c`.
- `a` is incremented for each new major realease (new architecture, main or logic incompatible with the previous version). In this case, `b` and `c` are initialized to zero.
- `b` is incremented for each new module version.
- `c` is incremented for each corrections pushed in a realease.

Example:
0.x.x : initiale realease / unstable framework
0.1.0 : first module implementedpremier module WireGuard fonctionnel
0.2.0 : second module implemented
…
1.0.0 : first stable realease
2.0.0 : architecture modified, new “main”, new logic incompatible with the previous version
